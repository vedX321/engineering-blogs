# Bench Notes — Engineering Blog

A plain HTML/CSS/JavaScript engineering blog designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new **public** repository on GitHub, for example `engineering-blog`.
2. Upload all files and folders from this project. Keep `index.html` at the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait a few minutes. Your site should appear at `https://YOUR-USERNAME.github.io/engineering-blog/`.

If you name the repository exactly `YOUR-USERNAME.github.io`, the site URL will instead be `https://YOUR-USERNAME.github.io/`.

## Customize before sharing

- Replace the site name “Bench Notes” with your preferred name.
- Replace the GitHub links (`https://github.com/`) with your profile or repository URL.
- Review and edit the starter article. It is a draft, not verified design guidance; add the exact datasheet revision, page references, schematic, and measurements before publishing.
- No build step or framework is required.
